# Contribution Guidelines

Thanks for helping make this list better. Please keep the bar high.

## Adding an entry

- Only add something you would genuinely recommend to someone building on the agentic web.
- The project must be **open source** (a clear OSI-approved or public-domain license) and **actively maintained**.
- It must be directly relevant to the agentic web: protocols and specs for agent-to-site interaction, discovery and site manifests, agent payments and commerce, MCP tooling, agent frameworks, or web/browser agents.
- Add it to the most fitting single section. Do not list the same project in multiple sections.
- Keep the list alphabetical only if the section already is; otherwise append.

## Format

Use this exact format, and nothing more:

```
- [Name](https://github.com/owner/repo) - Description.
```

- The description starts with a capital letter and ends with a period.
- Keep it to one neutral, factual sentence. No marketing language, emoji, or "the best".
- Link to the canonical source repo (follow redirects to the renamed/official one).

## Pull requests

- One pull request per project (or a small, coherent batch).
- Explain in the PR why the project belongs here.
- Run `npx awesome-lint` before submitting; the build must pass.
- Suggesting the removal of an unmaintained or dead entry is a welcome contribution too.
